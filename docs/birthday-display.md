# Экран дней рождения

В меню профиля администратора откройте **Администрирование → Экран дней рождения**
(`/settings/birthday-display`) и нажмите **Создать ссылку**. Скопируйте её в браузер
компьютера в холле и нажмите **На весь экран**. Вход в CRM на этом компьютере не нужен.

Экран показывает подтверждённых, неудалённых учеников (`students`) с днём рождения
на текущей неделе, с понедельника по воскресенье. Именинники сегодняшнего дня идут
первыми и выделены цветом и подписью. Фотография берётся из последнего значения
атрибута `photo`; без доступного снимка отображаются инициалы. Скрытые, секретные
и приватные фотографии не публикуются. Год рождения, контакты и другие поля карточки
на экран не передаются.

Карточки переключаются каждые 15 секунд. Данные обновляются каждую минуту и при
смене дня; после восстановления связи экран возобновляет работу автоматически.
Часовой пояс задаётся переменной `SCHOOL_TIMEZONE`, по умолчанию `Europe/Moscow`.
День рождения 29 февраля показывается 29 февраля в високосные годы.

Кнопки **Заменить ссылку** и **Отключить экран** отзывают старый ключ. Открытый экран
обнаружит отзыв при следующем обновлении (в пределах минуты при наличии связи).
После замены откройте новую ссылку на компьютере в холле.

Ключ находится во фрагменте ссылки (`#key=…`), не попадает в URL HTTP-запросов
и передаётся API в заголовке `X-Birthday-Key`. Он разрешает только список именинников
текущей недели и их текущие фотографии. Ответы API не кешируются. Ссылка и фотографии
доступны любому, у кого есть полный ключ.

При установке обновления требуется миграция `8db3c921a047` (`flask db upgrade`).
В Docker она выполняется штатной командой запуска backend. Первоначально ссылка
отключена; администратор включает её кнопкой **Создать ссылку**.
